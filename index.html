Add each cardholder's card number and password here, then just drop any mix of HDFC and YES Bank files — even the original bank filenames like 560103_1003…-678.pdf. The tool identifies each statement by the card number printed inside it (matched to the numbers below), so it doesn't rely on filenames; a locked file also needs the stored password to open (YES = DOB as DDMMYYYY, HDFC = mailer code like TRUU7000). Card numbers with a blank password still get identified — they just can't be opened until the password is added.
